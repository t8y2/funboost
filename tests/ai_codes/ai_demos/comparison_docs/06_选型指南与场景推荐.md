## 二、场景推荐

### 2.1 微服务架构

| 场景 | 推荐 | 原因 |
|------|------|------|
| Python 微服务间通信 | ✅ **Funboost** | 高性能、内置 FaaS |
| 多语言微服务 | ❌ Celery | Funboost 不支持多语言 |
| Python 微服务 + Node.js | ❌ Celery | 需要跨语言 |

**Funboost 示例：**

```python
from fastapi import FastAPI
from funboost.faas import fastapi_router

app = FastAPI()
app.include_router(funboost_router)

# 自动获得 /funboost/publish, /funboost/consume 等接口
```

### 2.2 Web 应用后端

| 场景 | 推荐 | 原因 |
|------|------|------|
| Django/Flask 异步任务 | ✅ **Funboost** | 简单、性能好 |
| 需要 Web UI | ✅ **Funboost** | 内置 FunWeb |
| FastAPI 集成 | ✅ **Funboost** | 一键路由 |
| Django + Celery | ❌ 保持 | 迁移成本高 |

**Funboost 示例：**

```python
# views.py
from funboost import boost, BoosterParams

@boost(BoosterParams(queue_name='send_email'))
def send_email_task(user_id, subject, content):
    send_mail(user_id, subject, content)

# API 视图
@router.post('/register')
def register(request):
    # 同步逻辑
    user = User.objects.create(...)
    # 异步发送邮件
    send_email_task.push(user.id, 'Welcome', '...')
    return JsonResponse({'status': 'ok'})
```

### 2.3 数据处理管道

| 场景 | 推荐 | 原因 |
|------|------|------|
| ETL 任务 | ✅ **Funboost** | 多进程叠加、高吞吐 |
| 大数据处理 | ✅ **Funboost** | Kafka/Redis 高效 |
| 机器学习训练 | ✅ **Funboost** | 多进程 + 多线程 |
| 实时流处理 | ✅ **Funboost** | 支持 Kafka Stream |

**Funboost 示例：**

```python
@boost(BoosterParams(
    queue_name='etl_pipeline',
    broker_kind=BrokerEnum.KAFKA_CONFLUENT,
    concurrent_mode=ConcurrentModeEnum.THREADING,
    concurrent_num=100,
))
def process_etl(data):
    # ETL 逻辑
    return transform(data)

# 多进程加速
process_etl.mp_consume(8)
```

### 2.4 爬虫/数据采集

| 场景 | 推荐 | 原因 |
|------|------|------|
| 高速爬虫 | ✅ **Funboost** | ASYNC 协程 + 高并发 |
| 分布式爬虫 | ✅ **Funboost** | Redis 多进程 |
| 爬虫 + 存储分离 | ✅ **Funboost** | 消息队列解耦 |

**Funboost 示例：**

```python
@boost(BoosterParams(
    queue_name='crawler',
    concurrent_mode=ConcurrentModeEnum.ASYNC,
    concurrent_num=500,
    qps=100,  # 限速
))
async def crawl_page(url):
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as resp:
            html = await resp.text()
            return parse(html)

crawl_page.mp_consume(4)  # 4 进程 × 500 协程 = 2000 并发
```

### 2.5 定时任务

| 场景 | 推荐 | 原因 |
|------|------|------|
| 简单定时任务 | ✅ **Funboost** | APScheduler 集成 |
| 分布式定时任务 | ✅ **Funboost** | Redis 锁 |
| 复杂 Cron | ✅ **Funboost** | APScheduler 完整功能 |
| Celery Beat 迁移 | ✅ **Funboost** | API 兼容 |

**Funboost 示例：**

```python
from funboost import ApsJobAdder

ApsJobAdder(daily_report).add_push_job(
    trigger='cron',
    hour=2, minute=0,
    kwargs={'type': 'daily'},
    id='daily_job'
)

ApsJobAdder(health_check).add_push_job(
    trigger='interval',
    seconds=30,
    id='health_job'
)
```

### 2.6 高可靠系统

| 场景 | 推荐 | 原因 |
|------|------|------|
| 金融交易 | ⚠️ 评估 | 需要专业支持 |
| 订单处理 | ✅ **Funboost** | 熔断器 + ACK |
| 消息通知 | ✅ **Funboost** | 死信队列 + 重试 |
| 支付系统 | ⚠️ 评估 | 需要充分测试 |

**Funboost 示例：**

```python
from funboost.contrib import CircuitBreakerBoosterParams

@boost(CircuitBreakerBoosterParams(
    queue_name='payment',
    broker_kind=BrokerEnum.REDIS_ACK_ABLE,
    max_retry_times=3,
    user_options={
        'circuit_breaker_options': {
            'strategy': 'rate',
            'counter_backend': 'redis',
            'errors_rate': 0.3,
        }
    }
))
def process_payment(order):
    # 支付逻辑
    pass
```

## 三、项目规模选型

### 3.1 小型项目（QPS < 100）

| 维度 | Funboost | Celery |
|------|----------|--------|
| 推荐度 | ⭐⭐⭐⭐⭐ | ⭐⭐ |
| 理由 | 上手快、代码少 | 太重 |

**Funboost 优势：**
```python
# 3 行代码启动
@boost(BoosterParams(queue_name='demo'))
def demo(x):
    return x * 2

demo.push(10)
demo.consume()
```

### 3.2 中型项目（100 < QPS < 10000）

| 维度 | Funboost | Celery |
|------|----------|--------|
| 推荐度 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| 理由 | 性能好、功能全 | 企业级但重 |

**Funboost 优势：**
- Redis 多进程可达 50000+ QPS
- 内置 Web UI
- 丰富的 Mixin 扩展

### 3.3 大型项目（QPS > 10000）

| 维度 | Funboost | Celery |
|------|----------|--------|
| 推荐度 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| 理由 | 性能最强 | 生态成熟 |

**Funboost 配置：**
```python
@boost(BoosterParams(
    queue_name='high_throughput',
    broker_kind=BrokerEnum.REDIS_ACK_ABLE,
    concurrent_mode=ConcurrentModeEnum.ASYNC,
    concurrent_num=1000,
    broker_exclusive_config={
        'pull_msg_batch_size': 100,
    }
))
async def fast_task(x):
    return process(x)

# 4 进程 × 1000 协程 = 4000 并发
fast_task.mp_consume(4)
```

### 3.4 超大型项目（多团队协作）

| 维度 | Funboost | Celery |
|------|----------|--------|
| 推荐度 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 理由 | 个人维护、文档少 | 社区大、生态全 |

**Celery 优势：**
- 成熟的生产案例
- 丰富的第三方集成
- 专业支持可用

## 七、迁移指南

### 7.1 Celery → Funboost

**评估阶段：**
1. 统计现有任务数量
2. 评估依赖的 Celery 特性
3. 计算性能需求

**迁移步骤：**

```python
# Step 1: 添加 Funboost
pip install funboost

# Step 2: 转换任务定义
# Celery:
from celery import Task
class MyTask(Task):
    def run(self, x):
        return x * 2

# Funboost:
from funboost import boost, BoosterParams

@boost(BoosterParams(queue_name='my_task'))
def my_task(x):
    return x * 2

# Step 3: 转换调用
# Celery:
result = my_task.delay(10)
print(result.get())

# Funboost:
result = my_task.push(10)
print(result.result)
```

**迁移对照表：**

| Celery | Funboost |
|--------|----------|
| `@celery.task` | `@boost(BoosterParams(...))` |
| `.delay()` | `.push()` |
| `.apply_async()` | `.publish()` |
| `result.get()` | `result.result` |
| `celery worker` | `.consume()` |
| `celery beat` | `ApsJobAdder` |

### 7.2 特性对比迁移

| Celery 特性 | Funboost 迁移 |
|-------------|---------------|
| `task_reject_on_worker_lost` | `REDIS_ACK_ABLE` |
| `task_acks_late` | 默认开启 |
| `rate_limit` | `qps` 参数 |
| `retry_backoff` | `is_using_advanced_retry` |
| Flower | FunWeb |
| Canvas | Workflow |

## 九、最终建议

### 9.1 选择 Funboost 如果：

```
✅ 你追求高性能
✅ 你使用 Python
✅ 你需要丰富的 Broker 支持
✅ 你需要内置监控/UI
✅ 你需要分布式限流/任务去重
✅ 你需要熔断器/微批处理
✅ 你喜欢简洁的 API
✅ 你的项目是新建的
```

### 9.2 选择 Celery 如果：

```
✅ 你需要多语言客户端
✅ 你的团队有 Celery 经验
✅ 你需要大规模生产验证
✅ 你的项目已经使用 Celery
✅ 你需要专业企业支持
```

### 9.3 混合使用

```python
# 部分任务用 Funboost
@boost(BoosterParams(queue_name='fast_tasks'))
def fast_task(x):
    return quick_process(x)

# 调用 Celery 任务
@boost(BoosterParams(
    queue_name='celery_tasks',
    broker_kind=BrokerEnum.CELERY
))
def celery_bridge(**kwargs):
    # 内部调用 Celery
    return my_celery_task.apply_async(kwargs)
```

## 十、配置模板

### 10.1 小型项目

```python
@boost(BoosterParams(
    queue_name='small_project',
    broker_kind=BrokerEnum.REDIS,
    concurrent_num=50,
))
def task(x):
    return process(x)
```

### 10.2 中型项目

```python
@boost(BoosterParams(
    queue_name='medium_project',
    broker_kind=BrokerEnum.REDIS_ACK_ABLE,
    concurrent_mode=ConcurrentModeEnum.THREADING,
    concurrent_num=100,
    max_retry_times=3,
    qps=1000,
    log_level=logging.WARNING,
))
def task(x):
    return process(x)
```

### 10.3 大型项目

```python
@boost(CircuitBreakerBoosterParams(
    queue_name='large_project',
    broker_kind=BrokerEnum.REDIS_STREAM,
    concurrent_mode=ConcurrentModeEnum.ASYNC,
    concurrent_num=1000,
    max_retry_times=5,
    is_using_distributed_frequency_control=True,
    broker_exclusive_config={
        'group': 'large_project_group',
        'pull_msg_batch_size': 100,
    },
    user_options={
        'circuit_breaker_options': {
            'strategy': 'rate',
            'counter_backend': 'redis',
            'errors_rate': 0.3,
        }
    }
))
async def task(x):
    return await process(x)

# 多进程
task.mp_consume(8)
```
