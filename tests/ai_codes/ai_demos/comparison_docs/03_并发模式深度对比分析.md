# 并发模式深度对比分析

> Funboost vs Celery 并发机制原理与性能对比

## 一、并发模式总览

### 1.1 对比总表

| 对比项 | Funboost | Celery |
|--------|----------|--------|
| **并发模式种类** | **5 种** | 4 种 |
| **模式选择** | 配置参数 | CLI 参数 |
| **多进程叠加** | ✅ 原生支持 | ❌ 互斥 |
| **自定义线程池** | ✅ | ❌ |
| **协程优化** | ✅ 完整 | ⚠️ 基础 |

### 1.2 Funboost 并发模式枚举

```python
from funboost.constant import ConcurrentModeEnum

class ConcurrentModeEnum:
    THREADING = 'threading'      # 线程池
    GEVENT = 'gevent'            # Gevent 协程
    EVENTLET = 'eventlet'        # Eventlet 协程
    ASYNC = 'async'              # 原生 Asyncio
    SINGLE_THREAD = 'single_thread'  # 单线程
```

## 二、线程模式 (THREADING)

### 2.1 原理架构

```
┌─────────────────────────────────────────────────────────────┐
│                    Funboost Consumer                         │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              FlexibleThreadPool                      │    │
│  │                                                      │    │
│  │   ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐       │    │
│  │   │ Thread │ │ Thread │ │ Thread │ │ Thread │ ...   │    │
│  │   │   1    │ │   2    │ │   3    │ │   4    │       │    │
│  │   └────────┘ └────────┘ └────────┘ └────────┘       │    │
│  │                                                      │    │
│  │   concurrent_num = 50 (可配置)                       │    │
│  └─────────────────────────────────────────────────────┘    │
│                          ↓                                   │
│              ┌──────────────────────┐                       │
│              │    Task Queue        │                       │
│              │  (queue.Queue)       │                       │
│              │                      │                       │
│              │  [msg1] [msg2] ...   │                       │
│              └──────────────────────┘                       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 代码示例

```python
@boost(BoosterParams(
    queue_name='threading_demo',
    concurrent_mode=ConcurrentModeEnum.THREADING,
    concurrent_num=50  # 50 个工作线程
))
def cpu_bound_task(n):
    # CPU 密集型任务
    result = sum(i * i for i in range(n))
    return result
```

### 2.3 线程池实现

```python
# funboost/concurrent_pool/flexible_thread_pool.py

class FlexibleThreadPool:
    """智能线程池"""
    
    def __init__(self, max_workers=50):
        self.executor = ThreadPoolExecutor(max_workers)
        self._work_queue = queue.Queue()
    
    def submit(self, fn, *args, **kwargs):
        """提交任务"""
        future = self.executor.submit(fn, *args, **kwargs)
        return future
    
    def map(self, fn, iterable):
        """批量提交"""
        return self.executor.map(fn, iterable)
```

### 2.4 兼容 Async 函数

```python
import asyncio

@boost(BoosterParams(
    queue_name='async_in_thread',
    concurrent_mode=ConcurrentModeEnum.THREADING,
    concurrent_num=50
))
async def async_task(url):
    """线程模式下也能运行 async 函数"""
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as response:
            return await response.text()

# Funboost 自动处理：在线程中创建事件循环运行 async 函数
```

## 三、Asyncio 协程模式 (ASYNC)

### 3.1 原理架构

```
┌─────────────────────────────────────────────────────────────┐
│                    Asyncio Event Loop                        │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐    │
│  │                    Task Queue                       │    │
│  │                                                      │    │
│  │   [Task1] [Task2] [Task3] [Task4] [Task5] ...       │    │
│  │                                                      │    │
│  └─────────────────────────────────────────────────────┘    │
│                          ↓                                   │
│  ┌─────────────────────────────────────────────────────┐    │
│  │                   Coroutines                          │    │
│  │                                                      │    │
│  │  协程1: await sleep() → await http_get() → 处理     │    │
│  │  协程2: await sleep() → await db_query() → 处理     │    │
│  │  协程3: await sleep() → await redis_get() → 处理    │    │
│  │   ...                                                │    │
│  │                                                      │    │
│  │   concurrent_num = 100 (可配置)                      │    │
│  └─────────────────────────────────────────────────────┘    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 代码示例

```python
import asyncio
import aiohttp

@boost(BoosterParams(
    queue_name='async_demo',
    concurrent_mode=ConcurrentModeEnum.ASYNC,
    concurrent_num=100  # 100 个并发协程
))
async def http_task(url):
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as response:
            return await response.text()

# 异步发布
result = await http_task.aio_push('https://example.com')
```

### 3.3 Asyncio vs Threading 对比

| 维度 | ASYNC | THREADING |
|------|-------|-----------|
| **适用场景** | I/O 密集型 | CPU 密集型 |
| **并发数** | 1000+ | 50-100 |
| **内存占用** | 极低 | 较高 |
| **GIL** | 无 | 有（但 I/O 时释放） |
| **调试难度** | 中 | 低 |

### 3.4 选择建议

```python
# I/O 密集型 → ASYNC
@boost(BoosterParams(
    concurrent_mode=ConcurrentModeEnum.ASYNC,
    concurrent_num=500
))
async def io_bound_task():
    await asyncio.sleep(0.1)  # 模拟 I/O
    return "done"

# CPU 密集型 → THREADING
@boost(BoosterParams(
    concurrent_mode=ConcurrentModeEnum.THREADING,
    concurrent_num=50
))
def cpu_bound_task():
    # GIL 在这里影响不大
    return sum(i*i for i in range(100000))
```

## 四、Gevent / Eventlet 协程模式

### 4.1 Gevent 原理

```
┌─────────────────────────────────────────────────────────────┐
│                    Gevent Hub                               │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              Greenlet Pool                           │    │
│  │                                                      │    │
│  │   Greenlet1: gevent.sleep() → socket.read()         │    │
│  │      ↓ 自动切换                                      │    │
│  │   Greenlet2: gevent.sleep() → db.query()            │    │
│  │      ↓ 自动切换                                      │    │
│  │   Greenlet3: gevent.sleep() → redis.get()           │    │
│  │                                                      │    │
│  └─────────────────────────────────────────────────────┘    │
│                          ↓                                   │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              Monkey Patched Libs                     │    │
│  │                                                      │    │
│  │   socket → gevent.socket                             │    │
│  │   time.sleep → gevent.sleep                          │    │
│  │   threading → gevent.thread                          │    │
│  └─────────────────────────────────────────────────────┘    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 Gevent vs Asyncio

| 维度 | Gevent | Asyncio |
|------|--------|---------|
| **语法** | 同步代码 | async/await |
| **学习曲线** | 低 | 中 |
| **第三方支持** | 需 monkey patch | 原生 |
| **调试** | 困难 | 较易 |
| **生态** | 老牌 | 新兴 |

### 4.3 代码示例

```python
# Gevent
from funboost import boost, ConcurrentModeEnum, BoosterParams
import gevent

@boost(BoosterParams(
    queue_name='gevent_demo',
    concurrent_mode=ConcurrentModeEnum.GEVENT
))
def gevent_task(url):
    from urllib.request import urlopen
    response = urlopen(url)  # 自动协程切换
    return response.read()

# Eventlet
@boost(BoosterParams(
    queue_name='eventlet_demo',
    concurrent_mode=ConcurrentModeEnum.EVENTLET
))
def eventlet_task(url):
    import eventlet
    with eventlet.Timeout(10):
        response = urlopen(url)
        return response.read()
```

## 六、Funboost 独有的多进程叠加

### 6.1 核心优势

```python
# Funboost: 多进程 + 多线程/协程 完美叠加！
@boost(BoosterParams(
    queue_name='high_throughput',
    concurrent_mode=ConcurrentModeEnum.THREADING,
    concurrent_num=50
))
def heavy_task(x):
    return x * x

# 8 进程 × 50 线程 = 400 并发！
heavy_task.mp_consume(8)
```

### 6.2 架构图

```
┌─────────────────────────────────────────────────────────────┐
│                    Process 1                                  │
│  ┌─────────────────────────────────────────────────────┐    │
│  │ ThreadPool (50 threads)                             │    │
│  │  [T1] [T2] ... [T50]                                │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│                    Process 2                                  │
│  ┌─────────────────────────────────────────────────────┐    │
│  │ ThreadPool (50 threads)                             │    │
│  │  [T1] [T2] ... [T50]                                │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│                    Process N (N=8)                           │
│  ┌─────────────────────────────────────────────────────┐    │
│  │ ThreadPool (50 threads)                             │    │
│  │  [T1] [T2] ... [T50]                                │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘

总并发 = 8进程 × 50线程 = 400 并发！
```

### 6.3 实现原理

```python
# funboost/core/muliti_process_enhance.py

def run_consumer_with_multi_process(booster, process_num):
    for i in range(process_num):
        p = Process(
            target=start_consumer_in_subprocess,
            args=(booster.boost_params, i)
        )
        p.start()

def start_consumer_in_subprocess(boost_params, process_index):
    # 每个进程创建独立的 Consumer 实例
    booster = Booster(boost_params)
    booster.consume()
```

## 七、Celery 并发模式

### 7.1 Celery 并发选项

```bash
# Prefork (多进程)
celery -A app worker -P prefork -c 4

# Eventlet
celery -A app worker -P eventlet -c 500

# Gevent
celery -A app worker -P gevent -c 500

# Solo (单进程单线程)
celery -A app worker -P solo -c 1
```

### 7.2 Celery vs Funboost 对比

| 维度 | Funboost | Celery |
|------|----------|--------|
| **多进程选择** | `mp_consume(n)` | `-P prefork -c N` |
| **多进程叠加** | ✅ 可叠加其他模式 | ❌ 只有 Prefork |
| **协程选择** | `concurrent_mode` | `-P eventlet/gevent` |
| **配置方式** | 代码/Pydantic | CLI 命令 |
| **灵活性** | 高 | 中 |

### 7.3 Celery 无法解决的问题

```python
# ❌ Celery 做不到：多进程 + 协程
celery worker -P prefork -c 4  # 只能选一个！
celery worker -P eventlet -c 500

# ✅ Funboost 可以：
@boost(BoosterParams(
    queue_name='hybrid',
    concurrent_mode=ConcurrentModeEnum.ASYNC,
    concurrent_num=1000
))
async def async_task():
    pass

# 4 进程 × 1000 协程 = 4000 并发！
async_task.mp_consume(4)
```

## 九、选型指南

### 9.1 快速选择

```
任务类型判断：
│
├─ I/O 密集型（HTTP/DB/Redis）？
│   ├─ 需要极高性能 → ASYNC (1000+ 并发)
│   └─ 喜欢同步代码 → GEVENT/EVENTLET
│
├─ CPU 密集型（计算/加密）？
│   └─ THREADING (多进程叠加更好)
│
└─ 需要严格顺序？
    └─ SINGLE_THREAD
```

### 9.2 场景推荐

| 场景 | 推荐模式 | 配置 |
|------|----------|------|
| Web 爬虫 | ASYNC | concurrent_num=500 |
| API 调用 | ASYNC | concurrent_num=200 |
| 图片处理 | THREADING + mp_consume(4) | concurrent_num=50 |
| 数据计算 | THREADING + mp_consume(8) | concurrent_num=100 |
| 顺序处理 | SINGLE_THREAD | - |
| 批量导入 | GEVENT | - |

### 9.3 高性能配置示例

```python
# Web 爬虫场景
@boost(BoosterParams(
    queue_name='crawler',
    concurrent_mode=ConcurrentModeEnum.ASYNC,
    concurrent_num=500,
    qps=100  # 限制每秒 100 次
))
async def crawl_task(url):
    async with aiohttp.ClientSession() as session:
        async with session.get(url, timeout=aiohttp.ClientTimeout(total=30)) as resp:
            return await resp.text()

# 启动 4 个进程
crawl_task.mp_consume(4)
# 总并发 = 4 × 500 = 2000

# 数据处理场景
@boost(BoosterParams(
    queue_name='processor',
    concurrent_mode=ConcurrentModeEnum.THREADING,
    concurrent_num=100
))
def process_data(data):
    return transform(data)

# 启动 8 个进程
process_data.mp_consume(8)
# 总并发 = 8 × 100 = 800
```
